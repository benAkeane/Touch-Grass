By Quinn Doyle, Marco Rubens, Ben Keene, and Tim Mäser
### The App:
 Touch Grass is a route based app that allows users to walk routes, and take drop pins along the way, where they take a picture to go with each pin. Users can share and view other users routes and track their friends activity. Routes track distance and elapsed time and the user can see this in real time.

### Implementation:
We used firebase and Swift to design and create the app. Firebase is used to store the user data, like login info, pins (images), and old routes. We also used Apple's map kit and location services to get the user's location and display it on the map in real time. 

### Testing:
First, to test in the simulator, run the TouchGrassApp package. To effectively test the program make sure you make an account on the login / register page or directly from the firebase. It is also important to make sure you allow the app to use your location as it is the core feature of the app.
